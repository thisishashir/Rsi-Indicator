# Quantitative Trading Strategy Analyzer

A modular Python research application for testing a configurable long-only mean-reversion strategy on OHLCV data from Yahoo Finance. It is a research and education tool, not a brokerage or live-trading system. Backtested results do not predict future returns.

## Features

- Yahoo Finance data for stocks, ETFs, and supported crypto symbols
- Wilder RSI, Bollinger Bands, SMA, EMA, and moving-average crossover states
- Configurable RSI/Bollinger/trend-filter entry and exit logic
- Next-bar execution model with transaction costs and slippage
- Full or fractional capital allocation
- Trade ledger, equity curve, drawdown, benchmark, and performance metrics
- Multi-ticker comparison without ranking assets as recommendations
- Streamlit controls, Plotly charts, and CSV exports
- Offline deterministic pytest coverage

## Architecture

`app.py` is a thin orchestration layer. `src/data` validates external data, `src/indicators` computes mathematical features, `src/strategy` produces state transitions, `src/backtesting` models execution and metrics, and `src/visualization` renders charts. Keeping these boundaries separate makes each part independently testable and explainable.

## Installation

Python 3.11 or newer is recommended.

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
```

Run the dashboard:

```powershell
python -m streamlit run app.py
```

Use `python -m streamlit` instead of the bare `streamlit` command so the launcher and installed packages come from the same Python environment. If multiple Python installations exist, activate the virtual environment first.

Run offline tests:

```powershell
python -m pytest -q
```

The first data request requires an internet connection. Streamlit caches the cleaned download by ticker, date range, and interval, reducing repeated Yahoo Finance requests. Indicator and backtest outputs are intentionally recalculated when controls change.

## Strategy

The default long entry requires RSI below its oversold threshold, price at or below the lower Bollinger Band, and a bullish short-versus-long SMA relationship. Exit conditions are RSI above overbought, price at or above the upper band, or an MA cross-down; the UI can combine exits with ANY or ALL logic and toggle components.

RSI uses Wilder-style exponential smoothing:

`RS = average gain / average loss`

`RSI = 100 - 100 / (1 + RS)`

Bollinger Bands use a rolling mean and population standard deviation:

`middle = rolling mean`

`upper/lower = middle +/- k * rolling standard deviation`

The backtester applies a signal observed at close `t` to the held position on bar `t+1`. This prevents the return generated by close `t` from using information that was only known at close `t`. Costs are charged proportionally on position changes. Yahoo Finance's end date is treated as exclusive by the provider.

## Metrics

- Total return: final portfolio value divided by initial capital minus one
- CAGR: annualized total return using elapsed calendar years
- Volatility: annualized standard deviation of strategy returns
- Sharpe estimate: annualized mean excess return divided by excess-return standard deviation
- Drawdown: equity divided by running peak minus one; maximum drawdown is its minimum
- Win rate: profitable closed trades divided by all closed trades
- Exposure: proportion of bars with a held long position
- Profit factor: sum of winning trade returns divided by absolute losing trade returns

The buy-and-hold series invests in the same starting capital at the first close and is shown as a benchmark, not as an investment recommendation.

## Limitations and responsible use

Yahoo Finance is an external provider and can fail, revise data, or omit symbols. The model is long-only, uses close-based execution for a transparent research approximation, excludes taxes and financing, and does not model corporate-action or market-impact details beyond the configured proportional slippage. RSI can remain overbought or oversold during strong trends. Parameter search can overfit historical noise; survivorship bias, data leakage, and regime changes remain research risks.

## Testing and future improvements

Tests use synthetic data and never call Yahoo Finance. Natural next improvements include walk-forward validation, an explicit execution-at-open model, richer corporate-action handling, portfolio-level position sizing across tickers, sensitivity analysis, and experiment provenance.
